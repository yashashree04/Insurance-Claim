# Insurance Claims Analytics Dashboard

## 📌 Overview
Developed an interactive Power BI dashboard to analyze insurance claims data, enabling insights into claim trends, policy performance, customer demographics, and business KPIs through dynamic visualizations.

## 🎯 Objectives
- Analyze insurance claim patterns and policy performance.
- Identify customer demographics and claim distribution.
- Build an interactive dashboard to support business decision-making.

## 🛠 Tools & Technologies
- Power BI
- Microsoft Excel
- Power Query
- DAX

## 📊 Dashboard Features
- KPI Cards
- Interactive Slicers
- Line Charts
- Bar Charts
- Pie Charts
- Ribbon Charts
- Matrix/Table Visuals

## 📈 Key Insights
- Claim trends over time
- Policy-wise claim analysis
- Customer demographic insights
- Claim amount distribution
- Business performance KPIs

## 💡 Skills Demonstrated
- Data Cleaning
- Data Modeling
- DAX Measures
- Power Query
- Data Visualization
- Business Intelligence

## 🚀 Resume Highlights
- Developed an interactive Power BI dashboard with KPI cards, slicers, and visualizations to analyze insurance claims, policy performance, customer demographics, and claim trends.
- Performed data modeling and created dynamic reports using bar, line, pie, ribbon, and matrix visuals to generate business insights and support data-driven decision-making.
